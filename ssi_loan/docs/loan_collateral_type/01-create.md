# Create Loan Collateral Type

## Pre-Condition

- User must belong to the **Loan Collateral Type** access group
  (`loan_collateral_type_group`).

## Flow

1. Open the **Loan > Configuration > Loan Collateral Types** menu.
2. Click the **Create** button.
3. Fill in the required fields:
   - **Name**: the name of the collateral type (e.g. Land, Vehicle,
     Equipment).
   - **Code**: fill with **/** to let the system auto-assign a code, or
     enter a unique code manually.
4. Click **Save**.

## Post-Condition

- A new record is created and is active by default.
- The record can now be selected as **Type** on loan collateral lines.
